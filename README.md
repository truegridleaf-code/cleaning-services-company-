## 🌟 Key Highlights

- **Mobile-First Responsive Design:** Fully optimized across Desktop, Laptops, Tablets, iPads, Android smartphones, and iPhones.

- **Performance & SEO Tuned:**
  - Semantic HTML5 structure with single `<h1>` per page
  - Structured Data (Schema.org `CleaningService` / `LocalBusiness` JSON-LD)

- **Interactive UI Components:**
  - Hero slider with swipe & touch support
  - 23-Service directory with category filtering tabs (`services.html`)
  - Interactive Before & After comparison slider
  - Instant Free Quote modal with form validation
  - Photo gallery with responsive lightbox preview
  - Interactive FAQ accordion & animated impact metrics counters
  - Floating WhatsApp chat & sticky Call Now button

## 🚀 How to Host on GitHub Pages

1. **Initialize Git & Commit:**
   ```bash
   git init
   git add .
   git commit -m "Initial commit - Truegrid Leaf website"
   ```

2. **Push to GitHub:**
   ```bash
   git branch -M main
   git remote add origin https://github.com/<your-username>/<your-repo-name>.git
   git push -u origin main
   ```

3. **Enable GitHub Pages:**
   - Go to your repository on GitHub.
   - Click on **Settings** > **Pages** (in the left sidebar).
   - Under **Build and deployment** > **Branch**, select `main` and root folder `/`.
   - Click **Save**.
   - Your website will be live in a couple of minutes!
